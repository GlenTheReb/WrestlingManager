# WM-016 — Visual identity and complex-screen design

Status: Incremental capability brief. An early token/layout slice may improve the implemented shell,
profile and roster surfaces now; complete coverage consumes WM-014, WM-035 and other proven M1/M2
screens. Reserved branch stem: `feature/wm-016-desktop-identity`.

## Player promise

Dense management screens feel coherent, fast and distinctly Wrestling Manager while keeping status,
evidence and actions legible at normal and compact desktop sizes.

## System contract

- Owns reusable visual tokens, layout primitives, information/action hierarchy and approved patterns.
- Consumes real workflows; it does not invent placeholder dashboards to demonstrate components.
- Emits accessible reusable patterns for office, profile, roster, creative, event and world screens.
- Navigation behavior is WM-017; show playback behavior is WM-014.

## Planned execution slices

1. Audit the implemented shell, profile and roster/search screens and codify typography, spacing,
   low-to-high rating colours, semantic icons, focus and status tokens.
2. Dense table/detail, timeline, alert and contextual-action patterns.
3. Responsive compact/normal workspace layouts and content hierarchy.
4. Cross-screen visual/accessibility regression evidence.

## Invariants and exclusions

- Design follows player tasks and information relationships, not equal card grids.
- Reusable components cannot hide domain-specific meaning behind generic labels.
- Colour is never the only state indicator; keyboard focus is visible.
- Do not redesign unimplemented screens or copy another game's layout.

## Decisions before relevant slices

PD-134 rules D1–D9 lock interface direction. The first execution ticket should use real implemented
screens rather than waiting for every management system. Each ticket must select representative WM
screens and measurable density/accessibility targets rather than mock metrics.

## Capability exit

Core workflows use a documented, accessible and performant design system without losing context or
becoming a generic web dashboard.
