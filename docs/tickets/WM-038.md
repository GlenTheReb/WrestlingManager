# WM-038 — Rival-company AI and CPU show simulation

Status: Capability brief; not implementation-ready. Depends on WM-028 and WM-033–037. Suggested
delivery lane: M5. Reserved branch stem: `feature/wm-038-world-simulation`.

## Player promise

Rival promotions pursue understandable goals, make constrained decisions and create an evolving
industry without omniscience or arbitrary advantages.

## System contract

- Owns bounded CPU decision policies, scheduling/booking abstraction and world-simulation orchestration.
- Consumes the same company, contract, finance, creative and event commands available to player systems.
- Emits chosen-action reasons, canonical CPU shows/results/history and bounded simulation diagnostics.
- WM-039 presents CPU shows; AI cannot mutate presentation or bypass owning-domain validation.

## Planned execution slices

1. Goal/resource/knowledge-based decision envelope and deterministic scheduling loop.
2. Hiring/release/development/finance decisions through shared commands.
3. Product, story, card and show simulation at scalable detail levels.
4. Competition, growth/decline/launch/closure/merge behavior plus multi-year soak/balance.

## Invariants and exclusions

- CPU decisions expose goal, considered inputs and constraints; hidden truth remains unavailable.
- Simulation-detail reduction preserves official outcomes/contracts/money/history invariants.
- Same seeds, versions and inputs reproduce decisions or provide explicit version boundaries.
- Do not script outcomes merely to create news or difficulty.

## Decisions before relevant slices

PD-121 must approve AI difficulty philosophy, planning horizons, simulation-detail tiers and acceptable CPU
company lifecycle frequencies.

## Capability exit

Representative companies evolve believably for years within performance budgets, use shared rules
and leave enough causal evidence to diagnose every major decision.
