# WM-039 — Global search and CPU-show viewer

Status: Incremental capability brief. The global-search shell may follow WM-017 and the WM-021
query foundation; each later domain registers when its canonical projection exists. Full CPU-show
viewing still depends on WM-013, WM-034 and WM-036–038. Suggested lanes: search shell in M1/M2,
complete industry viewer in M5. Reserved branch stem: `feature/wm-039-world-viewer`.

## Player promise

The player can quickly find any known worker, company, show, title, team, story or news item and open
an honest recap or stored presentation of simulated CPU shows.

## System contract

- Owns the global search bar/workspace, cross-entity registration/ranking, result routing and
  CPU-show view selection.
- Consumes paged domain queries, knowledge permissions, canonical show history and WM-013 events.
- Emits navigation only; search/viewing cannot change simulation or reveal hidden information.
- Worker Talent Search remains WM-021; shared query primitives should be reused.

## Planned execution slices

1. Early `Ctrl/Cmd+K` category-aware search bar and persistent full-page workspace, reusing WM-021
   primitives and registering only categories with canonical current projections.
2. Per-domain typed paged registrations, filters, ranking/highlighting, recent searches, entity deep
   links and knowledge/privacy handling as company/show/title/team/story/news domains land.
3. CPU card/result recap and available highlight/detailed stream playback after canonical history
   and WM-013 presentation events exist.
4. Large-world performance, stale/deleted entity handling and accessibility journeys.

## Invariants and exclusions

- Search indexes canonical IDs and projections; it does not duplicate mutable domain records.
- Unknown/private entities are omitted or represented according to PD-102.
- Recap, highlight and detailed views cannot contradict official results.
- Do not regenerate an old CPU show merely because detailed events were not retained.

## Decisions before relevant slices

PD-102 and PD-134 rules E3–E6 and U1–U2 lock global-search knowledge and retention direction. The
first execution ticket must define the registration contract, current categories and bounded query
budget; later tickets define ranking/permission fixtures only for the domains they add.

## Capability exit

Large-world search stays bounded and relevant, and every retained CPU show opens at an honest detail
level with stable navigation to its people, company and history.
