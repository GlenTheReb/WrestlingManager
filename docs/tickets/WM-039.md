# WM-039 — Global search and CPU-show viewer

Status: Capability brief; not implementation-ready. Depends on WM-034, WM-036–038 and WM-013 for
detailed playback. Suggested delivery lane: M5. Reserved branch stem: `feature/wm-039-world-viewer`.

## Player promise

The player can quickly find any known worker, company, show, title, team, story or news item and open
an honest recap or stored presentation of simulated CPU shows.

## System contract

- Owns cross-entity search projection, result routing and CPU-show view selection.
- Consumes paged domain queries, knowledge permissions, canonical show history and WM-013 events.
- Emits navigation only; search/viewing cannot change simulation or reveal hidden information.
- Worker Talent Search remains WM-021; shared query primitives should be reused.

## Planned execution slices

1. Typed paged global-search index/projection and entity deep links.
2. Filters, ranking/highlighting, recent searches and knowledge/privacy handling.
3. CPU card/result recap and available highlight/detailed stream playback.
4. Large-world performance, stale/deleted entity handling and accessibility journeys.

## Invariants and exclusions

- Search indexes canonical IDs and projections; it does not duplicate mutable domain records.
- Unknown/private entities are omitted or represented according to PD-102.
- Recap, highlight and detailed views cannot contradict official results.
- Do not regenerate an old CPU show merely because detailed events were not retained.

## Decisions before relevant slices

PD-102 and PD-122 must approve knowledge/search visibility, ranking priorities and CPU event-retention/detail policy.

## Capability exit

Large-world search stays bounded and relevant, and every retained CPU show opens at an honest detail
level with stable navigation to its people, company and history.
