# WM-041 — Native custom content and optional asset packs

Status: Capability brief; not implementation-ready. Stable IDs/validation are continuous constraints;
public editor/import/export follows WM-015–018 and PD-109. Reserved branch stem:
`feature/wm-041-custom-content`.

## Player promise

Players can create, validate, import and share native fictional databases/scenarios and optional
portrait/media packs without editing source code or endangering careers.

## System contract

- Owns public package manifests, editor/import/export workflow, dependency/conflict validation and
  asset sandbox rules.
- Consumes stable catalogues/IDs and version policies from every moddable domain.
- Emits validated immutable package versions and explicit career-creation/update choices.
- Runtime packages are data only: no executable code, path escape or network dependency.

## Planned execution slices

1. Mod-safe ID/catalogue audit and internal validation report format early.
2. Versioned scenario/database manifest plus deterministic import/export.
3. Native editor for release-approved worker/company/title/event/move/product content.
4. Optional portrait packs, then late optional sound/video packs and compatibility diagnostics.

## Invariants and exclusions

- Validation reports exact paths/entities/errors before any career mutation.
- Package versions/dependencies/conflicts resolve deterministically; imported IDs never collide silently.
- Missing assets use fallbacks and never affect simulation/save correctness.
- No unlicensed bundled likeness, music, video or arbitrary scripts.

## Decisions before relevant slices

PD-109 defines public scope/compatibility. Approve package licensing/attribution, update behavior,
asset formats/limits and editor usability targets.

## Capability exit

Approved content can round-trip through native tools, fail safely with precise diagnostics and create/
update test careers without code execution, path escape or optional-asset dependence.
