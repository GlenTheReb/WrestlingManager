# WM-019 — Release candidate and project cleanup

Status: Capability brief; not implementation-ready. Depends on WM-041 and accepted PD-110. Suggested
delivery lane: M6. Reserved branch stem: `feature/wm-019-release-candidate`.

## Player promise

Wrestling Manager installs, upgrades, launches and uninstalls predictably, protects careers and makes
only accurate public claims about what the release contains.

## System contract

- Owns installer/release packaging, release notes, licensing/notices and final documentation audit.
- Consumes verified artifacts and limitations from all release-scoped capabilities.
- Emits signed/versioned release artifacts only through a separately authorized publication process.
- It does not add gameplay features or silently clean unrelated user/repository data.

## Planned execution slices

1. Release manifest, licensing/notice and documentation completeness audit.
2. Windows installer/uninstaller and application-data preservation behavior.
3. Clean-machine install/upgrade/uninstall rehearsal with recovery fixtures.
4. Public feature/limitation review and separately authorized release handoff.

## Invariants and exclusions

- Uninstall never removes player careers without an explicit separate data-removal action.
- No secrets, generated caches, unlicensed assets or development-only flags ship.
- Release notes distinguish implemented, experimental and planned behavior.
- Commit, push, signing and publication always require current owner authority.

## Decisions before relevant slices

PD-110 and PD-128 must define release scope, channel, versioning, signing and supported Windows policy.

## Capability exit

The approved release candidate passes clean-machine lifecycle checks and its package, notices,
documentation, compatibility statement and feature claims agree with the verified build.
