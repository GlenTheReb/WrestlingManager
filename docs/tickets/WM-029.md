# WM-029 — Assisted/manual angle creator

Status: Capability brief; not implementation-ready. A minimal scene contract may support M2; full
capability depends on WM-007 and WM-028. Reserved branch stem: `feature/wm-029-angle-director`.

## Player promise

The player can build wrestling scenes through editable timed beats—dialogue, entrances, crowd work,
interruptions, attacks, interference, saves and exits—using assistance without surrendering control.

## System contract

- Owns structured angle plans, beat roles/timing/pacing, execution rules and angle report facts.
- Consumes characters/groups/storylines, participant skills, location, crowd and production context.
- Emits canonical executed scene facts for consequences, media and WM-013 presentation.
- Manual prose is presentation content attached to validated beats, not a source of canonical outcomes.

## Planned execution slices

1. Minimal location/participant/action beat schema replacing the current simple angle safely.
2. Timed pacing, dialogue and entrances/exits with validation.
3. Interruption/attack/interference/save/crowd-work execution and consequences.
4. Assisted editable proposals, full manual mode, recap/presentation and native workflow tests.

## Invariants and exclusions

- Assisted mode proposes; it never overwrites accepted manual beats.
- Participants, locations and actions validate against current availability and kayfabe context.
- Executed facts and planned text remain distinguishable after changes or failure.
- No runtime network model, theme songs, titantrons or full character animation.

## Decisions before relevant slices

PD-124 must approve beat/action catalogue, timing granularity, dialogue storage/moderation and how skill/context
changes execution without stealing authored meaning.

## Capability exit

Representative promo, confrontation and interference scenes can be planned, executed, resumed,
reviewed and presented through one structured contract without contradicting histories.
