# WM-014 — Text-led arena and show viewer

Status: Capability brief; not implementation-ready. Depends incrementally on WM-013. Suggested
delivery lanes: M2–M6. Reserved branch stem: `feature/wm-014-show-viewer`.

## Player promise

Matches and angles feel like a live wrestling production through timed text, scene/location cards,
portraits, crowd/commentary state, lighting and restrained effects—without pretending to animate
the wrestlers.

## System contract

- Owns playback state, view modes, accessible presentation and renderer-specific layout/effects.
- Consumes only WM-013 events/cues and optional validated local assets.
- Emits no simulation, result, history or consequence mutation.
- Audio/video pack loading remains WM-041; the viewer works fully without it.

## Planned execution slices

1. Accessible timed-text match view using the existing event stream.
2. Scene cards, crowd/commentary state and smart lighting/effect vocabulary.
3. Structured angle, entrance and interference playback.
4. Full/quick/highlight/instant parity, reduced-motion/audio controls and performance budgets.

## Invariants and exclusions

- Playback speed or mode never changes canonical events or consequences.
- Missing portraits/assets use deliberate fallbacks; text remains complete and readable.
- Effects support hierarchy and mood, not random spectacle detached from facts.
- No theme-song licensing, titantron pipeline or full wrestler animation.

## Decisions before relevant slices

PD-125 must approve visual density, default timing, effect restraint, portrait framing and accessibility defaults.

## Capability exit

Representative matches, angles and CPU-show recordings remain coherent across all view modes,
layouts, missing-asset states and reduced-motion settings.
